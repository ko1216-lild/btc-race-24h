A long-only trend bot that trades cbBTC against USDC on 1-minute bars with $1,000 of paper money. It enters when a 20-bar EMA crosses above an 80-bar EMA, staking 95% of equity, and exits the whole position on a +4% take-profit or a -2% stop-loss; on the frozen 24-hour dev window this made about +$37 over 4 trades after fees, slippage and pool impact.

## Run it

```sh
python3 main.py
```
